# Time Keeper

A personal time clock for tracking work shifts and figuring out pay.

- **Clock:** start, pause (break), resume, and end a shift.
- **History:** every shift by day. Add a shift by hand or tap one to edit or delete it.
- **Pay:** tap *Calculate my pay*, enter your hourly pay, and see what you earned since your last pay period. Save it to start the next period.

Everything is stored in your browser (localStorage). Use *Download backup* on the Pay tab to keep a copy.

## Run it locally

```
node serve.mjs
```

Then open http://localhost:5173.
